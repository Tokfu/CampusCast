CampusCast - Plain HTML, CSS and JavaScript

Files
- index.html: page layout and text
- style.css: design and responsive layout
- script.js: location search, live weather, forecasts and advice

How to run
1. Keep all three files in the same folder.
2. Open index.html in a browser. For reliable API access, you can also use the VS Code Live Server extension.
3. Make sure you have an internet connection because location search and weather data come from Open-Meteo.

No React, Vite, npm install or API key is required.

Features
- Current weather, rain probability, wind, humidity and UV
- Hourly forecast from 6 AM to 6 PM in the selected location's local time
- Preparation suggestions for rain, clothing, heat and outdoor plans
- Weather comparison for two locations (not route or travel-time planning)
- About page with the weather data source
